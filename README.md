# 💰 Salary Calculator

A sleek, responsive, dark-theme web application that helps users calculate their salary breakdowns quickly and easily.

**🌐 [Click here to view the live calculator!](https://govindchoudhary844.github.io/Salary-Calculator/)**

## ✨ Features
* **Live Calculation:** Instantly calculates salary breakdowns as you type.
* **Modern UI:** Clean, modern dark mode interface built with CSS.
* **Responsive Design:** Works seamlessly on both desktop and mobile devices.
* **No Dependencies:** Built entirely with pure HTML, CSS, and vanilla JavaScript.

## 🛠️ Technologies Used
* **HTML5:** For the structure of the application.
* **CSS3:** For styling, Flexbox/Grid layouts, and the dark theme.
* **JavaScript:** For the calculation logic and DOM manipulation.
* **GitHub Pages:** For hosting and deployment.
